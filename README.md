# APEP Brasil · mídia e documentos públicos

Repositório público da APEP Brasil (Associação Poder Emana do Povo) para tudo o que é público nos projetos da associação:

- **cidadao-no-conseg/**: Cidadão no CONSEG (cidadaonoconseg.com.br)
- **luminat21/**: LuminaT21 (luminat21.org)
- **apep/**: identidade e materiais da própria APEP

Aqui ficam os documentos públicos e as cópias dos dados oficiais que os sites usam, para não dependermos de terceiros, além do conteúdo de redes sociais e dos materiais impressos.

Regras:
- Só conteúdo público. Nada de dados pessoais além do que o poder público já publica.
- Sem fotos de crianças da família.
- Obras com autor (livros, monografias, músicas) não são copiadas: só o título e o link da fonte.
