# Documentos oficiais

Aqui entram as cópias dos documentos oficiais dos Downloads da Coordenadoria Estadual dos CONSEG: legislação, roteiro de reativação, processo eleitoral, administração, treinamento e desincompatibilização.

Hoje a pasta de arquivos da SSP responde **401** para todos os arquivos (veja `../dados-ssp/arquivos-bloqueados-401.md`). Quando o acesso for liberado, a coleta semanal copia os arquivos para cá automaticamente.

A biblioteca digital (monografias, artigos e e-books) e os hinos são obras com autor: ficam só listados, com o link oficial.
